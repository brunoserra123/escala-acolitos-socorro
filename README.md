# Escala de Acólitos · Perpétuo Socorro

App de escala de acólitos e coroinhas do Santuário Nossa Senhora do Perpétuo Socorro.

## Versão atual

O arquivo `versao.json` controla a versão que o app verifica automaticamente.

**Para publicar uma atualização:**
1. Atualize o código no Google Apps Script
2. Mude o número em `versao.json` (ex: `1.50`)
3. Atualize também a constante `VERSAO_APP` no `Codigo.gs`
4. Publique o deploy no Apps Script
5. Os usuários verão o aviso "Versão nova disponível"
